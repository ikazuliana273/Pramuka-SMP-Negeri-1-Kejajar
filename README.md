# Pramuka SMP Negeri 1 Kejajar

Website Gerakan Pramuka Gugus Depan SMP Negeri 1 Kejajar, Kabupaten Wonosobo.

Satu halaman statis (`index.html`) berisi profil, visi-misi, Tri Satya & Dasa Darma, kegiatan, agenda, pembina, galeri, dan kontak.

## Cara menampilkan online (GitHub Pages)
1. Buka **Settings → Pages**.
2. Pada *Source*, pilih branch `main` dan folder `/ (root)`, lalu **Save**.
3. Website akan tersedia di `https://ikazuliana273.github.io/Pramuka-SMP-Negeri-1-Kejajar/`.

Salam Pramuka!
